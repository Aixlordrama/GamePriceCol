# HackerRank Test

Carpeta para almacenar las soluciones de la prueba de HackerRank.

## Estructura

- **Preguntas 1 - 4**: Python 3 (según lo indicado por el usuario)
- **Preguntas 5 - 6**: MySQL / PostgreSQL

> Nota: En la foto enviada para la "Pregunta 1" el lenguaje seleccionado en HackerRank es **MySQL**, no Python 3.
> Por compatibilidad con lo que se ve en la pantalla, se incluye la solución en SQL. Si la prueba real
> exige Python 3 para esa pregunta, también se incluye la versión equivalente en Python.
